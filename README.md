# Krishna — Photography

Vite + React + TypeScript + Tailwind v4 + Lenis.

    npm install
    npm run dev      # http://localhost:3006
    npm run build    # output in dist/

- Text and chapter picks: src/content.ts. Set your real email there (brand.email); the contact form opens a drafted message to it.
- Photos and chapters: src/photos.json; image files in public/images/.
- Hero layers: public/layers/ (d = desktop, m = portrait).
